Personal github pages website
Now Showing Theme Explorer, an interactive 3d map of every correlated theme in the stock market
Ticker embeddings are clustered with UMAP and HDBSCAN to form themes, then labeled and related by an LLM. Node size reflects aggregate primary-member market capitalization for established themes, or the emerging-theme score for provisional themes.
Edges encode LLM-inferred economic relationships; their strength sets the force-directed layout’s target distance. Stronger links pull clusters closer together, while the simulation’s repulsive force separates weakly related or unlinked themes.
